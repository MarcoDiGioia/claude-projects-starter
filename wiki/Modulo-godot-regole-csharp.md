# godot-regole-csharp

Regole di codice, architettura e test per progetti Godot 4 in C

| | |
|---|---|
| Quando usarlo | Ogni nuovo progetto Godot 4 in C |
| Quando no | Progetti Godot in GDScript. |
| Richiede | regole-base |
| Azioni esterne | false |
| Versione | 1 |

Riferimenti del modulo: [https://github.com/MarcoDiGioia/claude-projects-starter/tree/main/moduli/godot-regole-csharp](https://github.com/MarcoDiGioia/claude-projects-starter/tree/main/moduli/godot-regole-csharp)

Senza percorsi locali né server MCP personali (`.mcp.json` resta fuori dal repository, vedi `godot-core-csharp/.gitignore`).

## Riferimenti
| Riferimento (nel modulo) | Destinazione (nel progetto) |
|---|---|
| `riferimenti/CLAUDE.godot.md` | in coda al `CLAUDE.md` del progetto (dopo `regole-base`) |

## Segnaposto
`APP_PROJECT`.

## Passi manuali
Aggiungere nel `CLAUDE.md` del progetto il percorso dell'eseguibile Godot sulle tue macchine.

## Verifica
Il `CLAUDE.md` contiene sia le regole base sia le regole Godot.
